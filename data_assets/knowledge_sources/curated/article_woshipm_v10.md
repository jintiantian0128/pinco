## 一、本期核心论点：AI行业进入"平台锁定"阶段，窗口期正在关闭

过去72小时，三件事情把AI行业竞争的本质彻底暴露：

1. **OpenAI CRO Denise Dresser的四页内部备忘录泄露**——The Verge获取全文，核心信息："市场竞争激烈程度前所未有"，直接攻击Anthropic"夸大收入数字"和"缺乏算力"
2. **Anthropic年化收入确认突破$300亿**——从2024年底的$10亿到2026年4月的$300亿，18个月增长30倍
3. **OpenClaw创始人Peter Steinberger在TED 2026演讲后宣布加入OpenAI**——OpenClaw转型为非营利开源项目

这三件事指向同一个结论：**AI行业正在从"谁的模型更强"转向"谁的平台更粘"**。模型能力趋于趋同（Jack Clark预言的"一年半后开源追平"），真正的战场在于——**谁能让用户/企业用了就走不掉**。

## 二、OpenAI备忘录深度解读："超级应用"的真实蓝图

### 2.1 备忘录核心内容

CRO Denise Dresser在4月13日给全员发了一封四页备忘录，被The Verge获取后公开。这是OpenAI迄今为止最坦诚的竞争战略表述：

**关于市场判断**：
> "市场竞争激烈程度前所未有。"
> "客户要的不是最好的模型——他们要的是**fit**：AI如何嵌入他们的工作流、知识、控制机制和日常运营。"

**关于Anthropic的攻击**：
- 指控Anthropic"夸大了其公开的营收数据"
- 称Anthropic"编码聚焦给了它一个早期楔子"，但"你不会想成为一个平台战争中的单产品公司"
- 称Anthropic没有收购足够算力是"战略失误"

**关于Spud（GPT-6）**：
- Spud不是一个独立模型，而是"基础能力层"
- 将让OpenAI所有核心产品"显著变好"
- 是"迭代部署策略"的一部分：推边界→发产品→从真实使用中学习→反馈到更好的系统

**关于平台战略**：
- OpenAI的多入口体系：**ChatGPT for Work**（知识工作）、**Codex**（软件开发）、**API**（嵌入式智能）、**Frontier**（Agent平台）、**Amazon Runtime**（生产执行）
- "更好的模型让平台更有价值，更深的集成提高迁移成本，每个运行在系统上的工作流都让OpenAI更难被替换"

### 2.2 PM视角：备忘录的五个关键信号

| 信号 | PM启示 |
|------|--------|
| **"客户要fit不要模型"** | 证实了V8提出的"产品组合竞争力"框架——单点模型优势≠产品竞争力 |
| **攻击Anthropic"单产品"** | OpenAI认为Anthropic的Code/Design/Cowork矩阵还不够构成"平台" |
| **Spud=能力层不是独立产品** | OpenAI选择把下一代模型作为"底层升级"而非"新产品发布" |
| **Frontier Agent平台** | 直接对标Anthropic的Managed Agents，企业Agent市场是核心战场 |
| **"每个工作流提高迁移成本"** | 明确表态：目标是**锁定**，不是**吸引** |

### 2.3 Dresser备忘录 vs Jack Clark演讲：两种世界观

| 维度 | OpenAI (Dresser) | Anthropic (Clark) |
|------|-----------------|-------------------|
| 核心信念 | 算力优势决定一切 | 能力窗口是暂时的 |
| 竞争策略 | 锁定用户+提高迁移成本 | 趁窗口期建生态位 |
| 对对手评价 | "算力不足的单产品公司" | "几个月后其他公司会有类似系统" |
| 算力规划 | 2030年30GW | 2027年7-8GW（Google/Broadcom TPU） |
| 商业化路径 | 超级应用+广告+企业 | 纯订阅/API → IPO |

**PM判断**：Dresser的备忘录暴露了OpenAI的焦虑——如果Anthropic真的只是一个"算力不足的单产品公司"，为什么要用四页纸来攻击它？答案是：**Anthropic的增长速度让OpenAI感到了真实威胁。**

## 四、OpenClaw TED 2026：从"逃出水箱的龙虾"到加入OpenAI

### 4.1 Peter Steinberger演讲核心内容

4月19日TED 2026舞台上，OpenClaw创始人Peter Steinberger分享了这个"全球增长最快的开源AI Agent"的诞生故事：

**起源**：三年毫无进展后，2025年初开始用编码Agent实验。"建软件就像打电子游戏，我停不下来。"

**转折点**：一个WhatsApp机器人被投放到公共社区做公测。"几小时内它处理了数百次交互。"

**OpenClaw定义**：不是单一应用，而是**"个人AI的操作系统"**——Agent可以管理通信、自动化日常工作、在后台持续运行。

**用户画像**："他们不是程序员，他们是建造者。真正的变革不是技术，是准入门槛的消失。"

**关键数据**：
- GitHub **100K+ Stars**
- 单周访问量**200万**
- Jensen Huang称之为**"下一个ChatGPT"**

**结语**："龙虾已经逃出了水箱，它不会回去了。"

### 4.2 Steinberger加入OpenAI、OpenClaw转为非营利

演讲后的重磅消息：Steinberger已正式加入OpenAI，OpenClaw同时转型为**非营利开源项目**。

**这意味着什么？**

1. **OpenAI的"acqui-hire"策略**：不买公司，买创始人——用人才对冲Anthropic在Agent领域的产品优势
2. **OpenClaw的中立化**：转为非营利后，OpenClaw可以继续被全行业使用（包括Anthropic的Claude Code），但Steinberger的创造力现在为OpenAI所用
3. **生态博弈**：回忆V6报道的"OpenClaw/Anthropic平台冲突"——Anthropic一度封禁了Steinberger。现在Steinberger加入了OpenAI，这段公案有了一个耐人寻味的结局

### 4.3 对AI PM的启示

Steinberger的故事验证了一个PM决策框架：

> **在AI时代，"44个项目几个月"的速度意味着瓶颈从"能不能造"变成了"该不该造"。**

PM的核心价值从"翻译需求为功能"变为**"在无限生产力下决定什么值得做"**。这与V9中"Product Engineer"角色兴起的趋势完全吻合。

## 五、营收竞赛的深层逻辑：为什么Anthropic可能已经超越OpenAI？

### 5.1 数据对比

| 维度 | OpenAI | Anthropic |
|------|--------|-----------|
| 年化收入（2026年4月） | ~$200亿 | **$300亿+** |
| 收入增速（2025→2026） | ~2x | **3.3x** |
| 估值 | IPO准备中 | $3800亿（私募$8000亿） |
| 主要收入来源 | ChatGPT订阅 + API + 广告（新增） | API + 企业订阅 |
| 企业客户策略 | 广覆盖，多产品入口 | 深渗透，工作流锁定 |
| 算力规划 | 30GW by 2030（自建Stargate） | 3.5GW by 2027（Google TPU） |

### 5.2 为什么Anthropic收入增速更快？

三个结构性原因：

**（1）企业定价权更强**：Mythos的$25/$125定价远高于GPT-5.4，但客户愿意付——因为安全能力是刚需

**（2）产品矩阵的交叉销售**：Claude Code用户升级到Opus 4.7 → 试用Claude Design → 部署Managed Agents → 每一步都增加ARPU

**（3）不做广告的信任溢价**：企业客户（尤其是金融、医疗、政府）对"不卖广告"的AI供应商有明显偏好。ChatGPT的$60 CPM广告正在推动对价格敏感的企业客户转向Claude

### 5.3 OpenAI的反击路径

Dresser备忘录透露了OpenAI的反击策略：

1. **Spud能力层升级**：不发独立新模型，而是让所有产品"显著变好"
2. **Frontier Agent平台**：企业Agent的默认部署平台
3. **算力碾压**：30GW vs 7-8GW的绝对算力优势
4. **超级应用合并**：ChatGPT + Codex + Atlas → 单一入口
5. **Amazon Runtime**：与AWS共建的生产执行环境

## 六、平台战争的终局分析：锁定vs.开放的囚徒困境

### 6.1 两种平台策略的博弈论分析

OpenAI和Anthropic的平台策略可以用一个简化的博弈矩阵来理解：

|  | Anthropic开放 | Anthropic锁定 |
|--|-------------|-------------|
| **OpenAI开放** | 双方靠模型竞争，用户自由流动 | Anthropic吃走高价值企业客户 |
| **OpenAI锁定** | OpenAI靠规模锁定消费者市场 | **双方各自锁定，市场分裂** |

**当前走向**：OpenAI选择锁定（备忘录明确表态），Anthropic在**表面开放但实质锁定**（产品矩阵形成闭环，但支持OpenClaw等第三方工具）。

**预测**：未来6个月将进入**"双锁定分裂"**——企业市场分为OpenAI阵营和Anthropic阵营，切换成本越来越高。这对AI PM意味着：**你现在选择的平台，可能在一年后变成你无法离开的平台。**

### 6.2 开源的"第三条路"

在两大巨头锁定的同时，开源阵营（Qwen 3.5/3.6、Gemma 4、DeepSeek V3.2、MiniMax M2.7）正在提供"逃逸速度"：

- 模型能力追赶闭源只差6-18个月
- Apache 2.0许可证意味着零平台锁定风险
- 本地部署满足数据主权需求

**PM战略选择**：

| 选项 | 适合场景 | 风险 |
|------|---------|------|
| 全押OpenAI平台 | 需要消费者规模+超级应用生态 | 被锁定+广告化影响信任 |
| 全押Anthropic生态 | 企业级安全需求+工作流深度集成 | IPO后战略可能变化 |
| 开源+自建 | 数据敏感行业+需要完全控制 | 需要自建运维能力 |
| **混合策略** | 核心能力用开源，前沿需求用闭源API | 架构复杂度高，但灵活性最强 |

## 七、本期框架："平台锁定度"评估工具

AI PM可以用以下5个问题评估自己的平台依赖风险：

| # | 评估问题 | 高风险信号 |
|---|---------|-----------|
| 1 | 你的核心数据是否存储在单一AI平台上？ | 是 → 迁移成本已经形成 |
| 2 | 你的工作流是否依赖平台特有API/功能？ | 是 → 技术锁定 |
| 3 | 你的用户是否通过该平台入口使用你的产品？ | 是 → 分发锁定 |
| 4 | 更换供应商需要多长时间？ | >3个月 → 深度锁定 |
| 5 | 你的合同是否包含排他条款或阶梯定价？ | 是 → 商业锁定 |

**得分**：3个以上"高风险信号" = 你已经被锁定，需要立即制定多云/多模型备份方案。
