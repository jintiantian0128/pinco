# Pinco 数据与知识资料（迁移归档）

本目录用于跨电脑迁移 Pinco 的非运行时代码资料，与小程序和后端源代码分开管理。

## 目录

- `knowledge_sources/`：AI 产品、AI 求职与职业发展知识原稿，以及产品方案原始文档。
- `job_datasets/`：研究期间收集的岗位快照、求职问题数据及其分析文件。
- `product_reports/`：Pinco 的产品策略、评测、复盘、One Pager、历史产品文档与配图。

## 使用边界

- 岗位快照和历史求职数据仅用于内部研究，不代表实时招聘信息，也不能直接当作当前职位推荐。
- 这些资料不是应用运行依赖，不会由构建或部署流程自动发布给小程序用户。
- 本目录不存放 API Key、微信密钥、云托管凭证、用户简历/会话/录音、数据库、日志、依赖或构建缓存。
- 继续迁移到其他设备前，请遵守资料来源的授权与公司数据管理要求；需要对外使用时另行核对版权和隐私。
