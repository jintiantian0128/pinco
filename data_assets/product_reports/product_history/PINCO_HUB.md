### 竞品分析

| 竞品 | 定位 | 优势 | 劣势 | Pinco 差异化 |
|------|------|------|------|-------------|
| **BOSS直聘AI** | 岗位推荐 | 数据量大，精准 | 没有学姐人设，不情感陪伴 | 职业规划+情感陪伴双线 |
| **牛客网** | 面经+刷题 | 社区活跃，内容丰富 | 被动检索，没有主动推荐 | AI主动引导+个性化 |
| **脉脉** | 职场社交 | 真实背景可见 | 没有 AI 辅助 | 专家连线+AI背书 |
| **简历 APP（超级简历等）** | 简历优化 | 模板丰富 | 功能单一，无对话 | 毒舌诊断+话术生成 |
| **Coze/扣子 AI 助手** | 通用 AI | 可定制 | 无垂直内容积累 | 职场垂直数据+专家网络 |

**核心差异化**：Pinco 是唯一同时具备「情感陪伴 + 职业规划 + 专家连线 + 真实招聘数据」的产品。

### 🚨 v7.1 紧急体验优化计划（基于 03-27 调研）
> **产品与研发 Agent 联合诊断结论**

#### 1. 伴学模块 & 花园内容无响应（研发主导）
- **诊断**：双 API (AIDP + Gemini) 如果同时网络不通（如本地 server 没开且 Gemini 被墙），异常捕获后未能正确重置加载状态（`isTyping` 和 `articleLoading` 未恢复），导致 UI 永久卡死。
- **修复计划**：
  - 完善 API 异常捕获机制，确保任何错误下都重置加载状态，并弹出友好的网络错误提示（"学姐网络开小差了，点击重试"）。
  - **降级策略**：为知识花园内置 3-5 篇本地 Markdown 缓存，断网时可直接阅读；对话模块增加本地静态应急回复库。

#### 2. “会员”模块突兀，升级为“我的”（产品主导）
- **诊断**：纯展示收费方案过于“割韭菜”，缺乏个人中心属性。
- **重构计划**：
  - 将底部 Tab 从【会员】改为【我的】（User/Profile）。
  - 页面顶部：展示用户头像、昵称、目标方向及当前积分。
  - 中部核心区：新增【我的预约清单】模块（关联 localStorage `pinco_appointments`），展示已预约的专家连线时间及倒计时。
  - 底部模块：将会员卡片（Pro/Plus）作为权益模块自然融入页面。

#### 3. 圈子“召唤学姐”千篇一律（产品+研发主导）
- **诊断**：当前报错直接走 fixed 兜底话术（"抱抱你..."）；即使调通，Prompt 也缺乏发散性。
- **修复计划**：
  - 丰富 Prompt：注入帖子的话题 Tag 和情绪分析，强制 LLM 生成差异化、带明确指导步骤的回复。
  - 增强兜底库：将固定的单句兜底改为 5-10 套不同风格的本地话术（如鼓励型、方法论型、毒舌型），随机触发。
