## 2. 产品概述
**项目背景**：针对 0-5 年职场新人面临的简历难写、面试怯场、职场沟通障碍等痛点，打造一款集 AI 简历诊断、模拟面试、职场问答于一体的智能助手。
**核心价值**：通过“Pinco 学姐”的人设，提供专业且有温度的职场指导，降低求职门槛，缓解职场焦虑。
**目标用户**：
*   **应届毕业生**：主要需求为简历优化、面试技巧。
*   **职场新人 (1-3年)**：主要需求为晋升答辩、职场沟通话术、跳槽规划。

## 3. 核心业务流程 (User Flow)
1.  **注册/登录** (微信一键登录/手机号)。
2.  **Onboarding (引导)**：
    *   设定求职意向（行业、职位、城市）。
    *   上传当前简历 (PDF/Word)。
3.  **主界面 (Dashboard)**：
    *   展示“求职竞争力评分”。
    *   推荐每日任务（如：优化项目经历、模拟面试 1 次）。
4.  **功能模块入口**：
    *   **简历诊所** -> 解析简历 -> 生成诊断报告 -> 一键润色。
    *   **模拟面试** -> 选择职位/场景 -> AI 提问 -> 用户回答 (语音/文字) -> AI 评分与建议。
    *   **职场树洞** -> 自由提问 (情感/职场困惑) -> Pinco 学姐回答。

## 4. 功能详细说明 (Functional Requirements)

### 4.1 简历诊所 (Resume Clinic) - P0
**描述**：用户上传简历，AI 基于 JD 进行匹配度分析并提供修改建议。
**输入**：
*   用户简历文件 (PDF/Docx)。
*   目标职位描述 (JD 文本或链接)。
**处理逻辑**：
1.  **解析**：提取简历中的 技能、项目经历、教育背景。
2.  **匹配**：计算简历与 JD 的关键词匹配度。
3.  **诊断**：识别缺失的关键技能、描述过于笼统的项目 (如 "负责..." 改为 "主导...并提升了 20%...")。
4.  **生成**：输出一份包含具体修改建议的 Markdown 报告。
**输出**：
*   竞争力评分 (0-100)。
*   3-5 条关键修改建议。
*   一键润色后的简历片段。

### 4.2 模拟面试 (Mock Interview) - P1 (文本版 P0)
**描述**：模拟真实面试场景，AI 扮演面试官进行提问。
**模式**：
*   **文本模式 (MVP)**：聊天窗口形式，AI 发送问题，用户输入文字回答。
*   **语音模式 (v1.0)**：实时语音通话 (TTS + ASR)。
**流程**：
1.  用户选择面试类型（行为面、技术面、压力面）。
2.  AI 生成第一个问题（基于简历或职位）。
3.  用户回答。
4.  AI 追问（基于用户回答的漏洞或亮点）。
5.  结束面试，生成《面试表现评估报告》。
**评估维度**：
*   逻辑性 (STAR 法则运用)。
*   匹配度 (是否体现职位所需能力)。
*   情绪/态度 (仅限语音模式)。

### 4.3 职场树洞 (Career Treehole) - P0
**描述**：基于 "Pinco 学姐" 人设的自由对话模块。
**功能**：
*   支持上下文记忆（记住用户的职业背景、之前的困惑）。
*   预设 Prompt 模板：
    *   "高情商回复"：输入对方的话 -> 生成 3 种不同语气的回复。
    *   "周报生成器"：输入本周工作流水 -> 生成结构化周报。
    *   "晋升答辩"：输入业绩 -> 生成 PPT 提纲。

## 5. 非功能需求 (Non-functional Requirements)
*   **响应速度**：文本对话响应 < 2s；语音对话延迟 < 1s。
*   **数据隐私**：用户上传的简历必须脱敏存储；用户可随时申请删除所有数据。
*   **并发支持**：MVP 阶段支持 1000 QPS。
*   **平台兼容性**：优先适配移动端 Web (H5) 及微信小程序，后续适配 iOS/Android 原生 App。

## 6. 数据埋点 (Analytics)
*   核心指标：
    *   **简历上传率**：进入简历诊所 -> 上传成功的转化率。
    *   **面试完成率**：开始面试 -> 生成报告的比例。
    *   **次日留存**：第二天再次访问的用户比例。
    *   **功能使用渗透率**：各功能模块的 DAU 占比。
