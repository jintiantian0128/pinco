# Pinco (CareerPilot) 🚀

> **Slogan**: 你的专属 AI 职业伴侣与导师
> **Mission**: 用 AI 驱动的职业指导赋能 0-5 年职场人

## 项目状态
🚧 **初始化中 (Initialization)**

## 核心功能 (MVP)
1.  **Pinco 智能体**: "温柔学姐" 人设对话引擎 (Text/Voice)
2.  **AI 简历诊所**: 简历解析 + JD 匹配 + STAR 法则重写
3.  **职场树洞**: 情感支持与 EQ 指导

## 技术栈 (拟定)
- **Frontend**: Next.js (React), TailwindCSS
- **Backend**: Python (FastAPI) or Node.js
- **AI Core**: LLM (Gemini/Claude/OpenAI), RAG (Vector DB)
- **Database**: PostgreSQL

## 目录结构
- `/docs`: 需求文档、BP、架构图
- `/src`: 源代码
- `/scripts`: 辅助脚本
